- Orientador de estágio: acompanho os estudantes nas empresas da região e faço a ponte entre a escola e o mercado.

| **[Prof. Jhordan Hub](https://app.jhordanleandro.com.br)** | Plataforma de estudos das minhas turmas: trilhas, testes de domínio, playground Python, notas e diário de estágio, com painéis para professor e administração. | Next.js · TypeScript · Prisma · MariaDB |
